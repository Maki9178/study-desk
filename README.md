## v0.4 合并版使用（2026-10-03）

在 Windows 开发目录双击 `Start-StudyDesk.cmd`，访问 `http://127.0.0.1:18763/`。`Stop-StudyDesk.cmd` 停止同目录服务。没有第三方运行时依赖；只使用本机已有 Node.js 和 Python。服务只监听回环地址，固定地址避免浏览器数据随端口变化，不配置开机自启。

首次可以不开启密码；之后在「密码设置」中开启、关闭或更换主密码。关闭保护需要验证原主密码，成功写入后才切换；数据保留。明文模式的资料和备份都没有加密，请不要存高价值网站密码。界面和备份名称标明保存方式。

这次将课桌与本机作业雷达的功能合并：截止分组、进行中状态、预计耗时、今日简报、ICS 双提醒、RADAR 书签文本、旧版 JSON 追加迁移、提醒数据导出和会话内文件绑定。旧 HTML 保留原处，未读取其浏览器存储；用户提供的备份已通过追加入口迁移到正式 Edge 资料库，9 个平台、0 份作业，刷新后数量保留。

首页最多建议三项未完成任务：逾期、24 小时内、72 小时内、7 天内、无截止、7 天以后依次排序。完整任务清单同时保留。文本预览标记已有和同批重复项，可能重复项提醒核对；保存时再次去重。来源 ID 优先使用 `(siteId, externalId)`，无完整来源 ID 时比较网站、标准化标题与截止时间。

`core.js` 保存迁移、去重、预览和排序纯逻辑。继续读取原 schemaVersion 1 和加密备份，保留扩展字段，拒绝未知版本。旧程序不保证能读取新明文备份和新状态字段。

导入备份先在内存验证，成功后才替换本地存储；错误密码、损坏数据、未知版本、取消和写入失败保留当前资料。恢复前自动下载原备份，但浏览器可能拦截下载，请自行确认文件。没有主密码找回功能。

日历仅导出有截止时间的未完成作业，使用 UTC 时间和提前一天、两小时的提醒。导入到日历后才生效，是静态文件，后续修改需重新导出，尚未测试手机日历通知。

「导出提醒数据」与「绑定提醒文件」只输出平台名称/入口和作业，不输出网站账号、密码、登录方式或平台备注。提醒数据仍为明文，请妥善保管；绑定仅在当前会话有效，重新打开需重新绑定。兼容随项目提供的 `每日提醒.ps1`，可手动运行：

```powershell
powershell.exe -NoProfile -File .\每日提醒.ps1 -DataFile "$env:USERPROFILE\Downloads\作业雷达提醒数据.json" -Quiet
```

没有注册计划任务、自动抓取或云同步。旧版书签复制出的 `RADAR|标题|链接|选中文本` 可在文本导入窗口使用；这不代表读取整站作业。没有保存、上传或自动处理登录 Cookie。

开发检查：`npm.cmd test`；打包：`python build.py`。打包明确使用 UTF-8，内嵌 core.js、radar.js、app.js 和全部 CSS。独立演示 `?demo=1` 与正式库分开；演示原密码为 `study-desk-demo-only`，只包含虚构资料。

云端交接声称的提交 `c04bf43` 未在本机取得，早期远程 main 核对时为 `9175c2c`。本版依据交接的功能要求在本机实现，不宣称包含该提交源码；v0.5.0 已于 2026-10-09 推送 GitHub。核心与应用事件处理回归通过，完整浏览器文件导入仍受扩展文件访问权限限制；直接 file:// 打开被浏览器安全策略阻止，未绕过。

## 初次 Windows 适配记录（v0.2）

新增：文本导入时填写课程并跳过重复作业；恢复备份前验证密码及数据；恢复前下载当前密文备份；保存失败回滚；多窗口冲突检测；窄屏锁定按钮；独立演示库。保持原加密备份、`schemaVersion:1` 和正式存储键兼容。

同一网站、标准化标题、截止时间相同的作业跳过，保留已完成状态；标题或日期改变视为新作业，请核对。浏览器可能拦截恢复前的自动下载，替换前仍应手动导出并确认文件保存成功。忘记当前密码时可以在锁定窗口从备份恢复，仍需知道备份密码。

不要混用 `localhost`、`127.0.0.1`、不同端口或浏览器配置文件：它们的存储独立。旧单文件版本和服务版也分别保存，迁移时导出再导入。

独立演示地址为 `?demo=1`，与正式资料库分开保存。本机演示密码为 `study-desk-demo-only`，仅用于虚构测试数据；正式资料库请自行设置密码。

## 快速使用

下载 `dist/课桌-本地原型.html`，用最新版 Chrome 或 Edge 打开，无需安装依赖。设置主密码后即可添加网站与作业。

- 网站、用途、账号和可选密码统一管理。
- 关键词检索、分类筛选、截止时间排序与完成状态。
- 从复制的网页文本读取候选作业，核对后导入。
- 整个资料库在本地加密保存，可导出 / 导入加密备份。
- 10 分钟不操作自动锁定。

当前没有实现直接读取登录网站的自动同步。先使用文本导入，再逐站添加适配器。高价值账号建议使用经过审计的密码管理器。

## 开发

模块化源代码：`index.html`、`style.css`、`app.js`。没有运行时依赖。

```sh
python3 build.py
node --check app.js
node tests/core.test.cjs
```

也可以用本地服务器打开模块化版本：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

之后访问 `http://localhost:8000`。不要将这个含私人资料的本地实例开放到公网。
