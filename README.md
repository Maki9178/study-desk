# 课桌 · Study Desk

本地网站与作业管理器：把课程网站、登录账号和作业截止时间放到同一处。

## 快速使用

下载 `dist/课桌-本地原型.html`，用最新版 Chrome 或 Edge 打开，无需安装依赖。设置主密码后即可添加网站与作业。

- 网站、用途、账号和可选密码统一管理。
- 关键词检索、分类筛选、截止时间排序与完成状态。
- 从复制的网页文本读取候选作业，核对后导入。
- 整个资料库在本地加密保存，可导出 / 导入加密备份。
- 10 分钟不操作自动锁定。

当前没有实现直接读取登录网站的自动同步。先使用文本导入，再逐站添加适配器。高价值账号建议使用经过审计的密码管理器。

## 开发

模块化源代码：`index.html`、`style.css`、`app.js`。没有运行时依赖。

```sh
python3 build.py
node --check app.js
node tests/core.test.cjs
```

也可以用本地服务器打开模块化版本：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

之后访问 `http://localhost:8000`。不要将这个含私人资料的本地实例开放到公网。

## 数据与备份

当前浏览器本地存储保存 AES-GCM 加密资料库。主密码不会保存，也无法找回。换浏览器、移动本地文件或清除浏览器数据前请导出备份。
